# Responsive Portfolio Website

## Lab Title
Design and Development of a Responsive Portfolio Website.

## Description
This project is a personal portfolio website developed using HTML
and CSS. It contains About, Skills, Projects and Contact sections.

## Technologies Used
1. HTML5
2. CSS3
3. Flexbox
4. CSS Grid
5. Media Queries
6. CSS Animations

## Features
- Responsive website layout
- Flexbox for header and hero section
- Grid layout for skills and projects
- Hover effects on links, buttons and cards
- Animated heading using keyframes
- Contact form

## Responsive Breakpoints

Mobile: Up to 600px

Tablet: Up to 900px

Desktop: Above 900px

## Steps to View Responsive Behaviour

1. Open index.html in a browser.
2. Open browser developer tools.
3. Enable device toolbar.
4. Test the website at different screen sizes.
5. Check mobile, tablet and desktop layouts.
